内容工坊开发进度

版本：2.0.0（第一轮） 更新时间：2026-10-20 现网：GitHub Pages / content-studio，同一地址增量更新。

第一轮已实现

  • 经营资料与账号定位独立配置。多个小红书账号各自保存赛道、受众、语气、作者偏好与正反例。
  • 素材分为共享、经营资料专属和账号专属。保留来源作者、链接、授权状态、原始数据与示例标记。
  • 内容任务关联目标账号、经营资料、本次视角、目标和证据素材。禁止跨账号误用专属素材。
  • 文案与图片工作室分开，通过 taskId 关联。图片支持模板排版、分页预览、导出，Skill仅复制提示词手动执行。
  • 对标研究项目支持账号研究、单篇拆解和专题综合。专题至少两条素材；单篇恰好一条。
  • 采集JSON 1.0校验预览、归属选择、去重、批次记录。重复资料不覆盖人工编辑，新的观察值另存快照。
  • 复盘档案支持任务、证据、正反例、作者偏好及建议。建议可转新任务，偏好由作者明确确认后加入账号档案。
  • 保存时建立版本快照，素材标注缺失项和完整度。未提供的互动数据不补零。
  • 使用原存储键。升级前自动备份；支持旧备份1、新备份2和旧记录数组的合并导入。ID冲突另存，依赖级联重映射。
  • 保留旧选题、对标、三平台草稿、审核排期、发布登记、数据记录与图文/视频导出入口。

验证记录

  • TypeScript类型检查、生产构建。
  • 11项迁移/导入/任务回归：原ID与发布状态保留、迁移幂等、错误版本拒绝、预览无写入、示例与null保留、去重与观察快照、跨账号素材拦截、历史与版本冲突、依赖重映射、预览过期和配额失败保护、旧/新备份恢复、审核修改退回。
  • 发布后浏览器已实测：示例账号创建、账号专属JSON导入与完整度、素材关联任务、独立图片工作室方案保存、文案结果导回且关联不可改写、完整备份下载、复盘建议转新任务。补充修复：示例标识继承与图文提示词。

明确未接通

  • 不开发采集器；不自动抓正文、图片、账号动态或网站指标。
  • 收藏软件、Android分享入口由独立采集项目实现，本轮只定义接收JSON及人工归属。
  • 默认外部AI工作流。用户API直连、服务端代理、API密钥管理暂未实现，不需要输入密钥。
  • Skill不会自动安装/运行；图片素材字节上传与AI出图结果接收留待后续。
  • 无跨设备云同步。localStorage有容量限制，需定期完整备份。
  • 原站云端图片只有元数据；备份不携带原Cloudflare存储的图片字节。
  • 商单、口播视频和跨平台改编不在本轮开发范围，原有视频导出保持兼容。

下一轮建议（未实施）

1. 与独立采集项目用真实导出文件联调，按版本升级协议，不在网页内复制采集能力。 2. 图片生成结果的文件接收与资源存储，图文与文案版本联动，增加Skill配置库。 3. 深化复盘指标缺失语义、证据级引用、实验对照和建议执行回流。 4. 如需要跨设备或团队协作，再确定数据库、账号权限与云端迁移方案。

工程维护

当前公开仓库根目录为可直接运行的自包含index.html，以及guide.html、progress.html、interface.html与协议JSON。完整可编辑源码、测试和构建脚本在source-code.zip中。

解压后进入web目录：npm ci → npm run check → npm test → npm run build → npm run package。生产打包将静态入口与公开文档输出到根目录。更新时同时提交index.html、文档与source-code.zip；Pages仍使用main根目录。
