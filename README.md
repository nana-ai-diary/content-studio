# 内容工坊 2.1 · 小红书图文优先

在原有内容工坊上增量更新。支持同平台多个不同定位账号，将经营资料、账号定位、本次表达视角和内容目标分别配置；不按商户/博主身份锁定流程。

## 第二轮

- 赛道下拉与细分方向多选，自定义方向和旧值保留。
- 小红书Excel多工作表本地解析；笔记累计、账号周期、每日趋势分开保存。
- 截图上传、压缩证据、AI识别与结果核对，复盘建议转任务。
- 对标主页档案、作品研究、近期更新、低粉高赞筛选与选题入库。
- 飞书CSV导出，可选独立桥接；自带兼容视觉API可选且密钥只在页面内存。
- 常用导航收拢；完整备份包含复盘数据和压缩截图。

## 第一轮（继续保留）

- 经营资料与账号档案、共享/经营资料/账号专属素材。
- 内容任务关联证据，文案工作室与图片工作室通过taskId关联。
- 外部AI提示词与结果导回；图片模板、Skill手动执行说明和预览。
- 对标账号研究、单篇拆解、多篇专题综合。
- JSON采集接口1.0，校验预览、归属选择、去重、历史观察与批次。
- 历史快照、完整度、正反例与作者偏好，复盘建议可转新任务。
- 原存储键不变，升级/导入前备份，支持旧备份1与新备份2的合并恢复。

旧选题、三平台草稿、审核排期、人工发布登记、表现记录、PNG图文发布包和无配音视频导出继续保留。

## 文档

- `guide.html`：功能说明。
- `progress.html` / `DEVELOPMENT.md`：每轮开发进度、验证和后续范围。
- `interface.html` / `INTERFACE.md`：版本化采集导入和备份协议。
- `collection-example.json`：明确标识为示例的联调文件。
- `collection-schema.json`：采集输出JSON Schema。
- `source-code.zip`：完整可编辑源码、测试、锁文件和构建脚本。

## 使用边界

数据只保存在当前浏览器；清理站点数据后会丢失，请定期导出完整备份。采集器在独立项目开发，网页不重复开发采集能力。

主页自动采集、定时监控、Skill自动执行、AI直接出图、自动发布与跨设备同步尚未接通。默认外部AI导回，也可自带兼容API；飞书自动写入需独立桥接服务，当前CSV人工导入可用。截图只保存压缩副本，原件请自行留存。商单、口播视频、跨平台改编留待后续。

## 开发与发布

解压源码包，进入web目录，Node.js 22.13+：`npm ci` → `npm run check` → `npm test` → `npm run build` → `npm run package`。

`index.html`已内联全部应用资源，根目录可直接部署。GitHub Pages继续使用main分支根目录。修改后同步更新网页、文档与源码包。
