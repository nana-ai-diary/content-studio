内容工坊 · 功能说明

用于管理小红书、抖音与 X 的自媒体内容流程。此页面无需登录或运行 JavaScript，可直接阅读和分享给 AI 对话。

GitHub Pages 独立版：内容保存在当前浏览器；不连接原网站的云端资料。清理站点数据后本地记录会丢失，请及时导出JSON备份。在线AI、热点获取、封面上传、自动发布尚未接入。

工作台

查看选题储备、制作中内容、排期和发布记录。从业务配置、示例选题或新建选题开始。

热点雷达

提供 AIHOT、NewsNow、X榜单的来源入口，以及手动导入。静态版不提供在线获取服务；X榜单通过手动导入使用。

选题库

管理标题、切入角度、来源链接、参考正文、推荐理由、内容方向与目标平台。支持搜索、筛选和示例试跑。

对标研究

保存账号名称、平台、内容链接、正文或视频转写，编辑拆解备注，通过提示词导入 AI 分析。链接不会自动抓取全文，尚未提供自动账号监测。

内容制作

一个选题分别创建小红书、抖音和 X 草稿，独立编辑标题、正文、标签、图文分页、封面、视频脚本和视觉风格。静态版暂不提供封面素材上传。

审核与排期

内容依次经过草稿、待审核、已批准、已排期、已发布。修改已批准内容会撤回批准，需重新审核。排期仅保存计划，实际发布后手动登记平台链接。

导出

支持发布文案与分镜 Markdown、包含 PNG 图片和文案的 ZIP 发布包、无配音的图文轮播 WebM 视频。图文为 1080 × 1440 像素。

效果复盘

手动记录已发布内容的浏览、点赞、评论、收藏和咨询累计值，查看每条内容最新记录的合计。尚未自动回收平台表现数据。

业务与设置

配置品牌名称、赛道、受众、产品服务、内容目标、语言、语气、表达边界、已确认事实与启用平台，支持 JSON 数据备份。

使用顺序

  1. 填写业务与设置，或点击“用示例选题试跑”。
  2. 创建选题，制作各平台草稿，编辑正文与图文分页。
  3. 完善真实信息，提交审核，批准后设置发布计划。
  4. 导出发布包，在平台人工发布，回到工作台登记链接和表现。
